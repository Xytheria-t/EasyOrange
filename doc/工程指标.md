### 1.3 AI 工程化深度

> **8 件套全落地**。当前口径为两条 AI 主线链路（卖家「发布助手」：拍照识别单入口，一次产出属性 + 建议价 + 标题描述；买家「对话式找货」：同一套 RAG 链路检索在售资产）；两条链路的 LLM 调用全部接入 `@TokenBudget` 日预算治理 + Prompt YAML 版本化 + **自治式 Agent 编排（多步工具循环，决策权在模型）**。原口径「6 个决策点（4 LLM + 2 规则引擎）」、独立的估值 / 文案入口、搜索页「AI 智能搜索」四路增强均为演进痕迹：后者经核查无一具备 Agentic 能力（规则算出的标签贴 AI 名、LLM 摘要不回流检索也不改排序），已于 2026-09 整节删除，只留 ES 语义检索；这些均仅作被追问时的历史交代，不再对外引用。

> **列表重渲染口径与结论（2026-09-24 实测）**
>
> 测的是 React reconciliation + DOM 变更提交（`<Profiler>` 的 `actualDuration`），**不含浏览器 paint / layout**——而后者也不是 `useMemo` / `React.memo` / React Compiler 能消除的部分，所以该口径正好覆盖这次决策关心的范围。jsdom 环境，绝对值不可直接当用户侧指标引用。

| 限流阈值 | GET 走本地 **200 次/60s/IP**；写走 Redisson 分布式令牌桶 **30 次/60s/IP**；Redis 故障 fail-open |
| 防重（防连点） | `RateLimitFilter` **3s** 间隔 + 方法 + 请求体 hash（不缓存响应，与幂等互补） |
| DLQ 三级重试 | `DlqRetryScheduler` 每 **5 分钟**扫描 → 重试 **< 3 次**重投主队列 → 超过转储 `eo.dlq.terminal`（DLQ 层固定轮询间隔，指数退避由主队列 RetryTemplate 承担） |
| 缓存 TTL 与三防 | 统一 TTL **30m**（`easyorange.cache.default-ttl`）+ 写路径显式 `@CacheEvict` + `CacheErrorHandler` fail-open；TTL 抖动 `easyorange.cache.ttl-jitter` 默认 **0.1**（防雪崩）+ `@Cacheable(sync=true)` 单飞重建（防击穿）+ null 结果缓存（防穿透） |

## 三、已知限制

### 3.1 WSL2 环境限制

| 限制 | 影响 | 项目应对 |
|---|---|---|
| Mockito inline mock maker 在 WSL2 下 ByteBuddy attach 失败 | 配置 `mock-maker-subclass` 后已跑通（测试全绿） | 原生 Linux / CI 无需该配置 |
| Testcontainers 依赖 ryuk sidecar 镜像，无代理 Docker 下拉取失败（`disabledWithoutDocker=true` 会把用例**静默跳过**、掩盖真实装配缺陷） | 曾使集成测试形同虚设；改用 docker-compose 后不再是限制 | 弃用 Testcontainers，改 Spring Boot `spring-boot-docker-compose` 复用仓库根 `compose.yaml`（start-only）；**10 个 `*IT` 真实连 MySQL/Redis/RabbitMQ**，经 failsafe 绑定 `mvn verify` 运行（CI 门禁 `backend-ci.yml` 以 `-DskipITs=true` 跳过，`ai-eval.yml`（push 限定 AI 面 + 按需 dispatch）在 runner 上跑 GoldenSetRegressionIT）——决策与遗留代价见 [技术债务清单 TD-001](./技术债务清单.md) |
| Lombok JDK 25 弃用警告 | 启动打印 unsafe 警告 | 已配 `--sun-misc-unsafe-memory-access=allow` |

### 3.2 ES 在 dev / prod 默认启用

Elasticsearch 仍由 `@ConditionalOnProperty` 控制装配，但 prod / dev 都显式 `enabled: true`：**dev 起后端前必须先起 ES**（`docker compose --profile search up -d elasticsearch`，fullstack 栈已把 ES 纳入 app 依赖），否则启动期建索引失败；只有 it / 裸跑基文件可无 ES 运行，此时检索降级为 MySQL LIKE（召回质量不达标）。收益是「ES 搜索」相关指标（混合检索延迟、hit@5）在本地与生产走同一条路径，不必再找装好 ES 的环境单独采集。决策与残留代价见 [技术债务清单 TD-003](./技术债务清单.md)。
