### 3.2 ES 在 dev / prod 默认启用

Elasticsearch 仍由 `@ConditionalOnProperty` 控制装配，但 prod / dev 都显式 `enabled: true`：**dev 起后端前必须先起 ES**（`docker compose --profile search up -d elasticsearch`，fullstack 栈已把 ES 纳入 app 依赖），否则启动期建索引失败；只有 it / 裸跑基文件可无 ES 运行，此时检索降级为 MySQL LIKE（召回质量不达标）。收益是「ES 搜索」相关指标（混合检索延迟、hit@5）在本地与生产走同一条路径，不必再找装好 ES 的环境单独采集。决策与残留代价见 [技术债务清单 TD-003](./技术债务清单.md)。
