## 三、已知限制

### 3.1 WSL2 环境限制

| 限制 | 影响 | 项目应对 |
|---|---|---|
| Mockito MockMaker attach 受沙箱限制 | 单元测试无法跑通 | 文档化"应在 Linux 原生或 CI 跑测试" |
| Docker 兼容性 | Testcontainers 集成测试无法跑 | 全量改为单元测试 + Mockito mock |
| Lombok JDK 25 弃用警告 | 启动打印 unsafe 警告 | 已配 `--sun-misc-unsafe-memory-access=allow` |

### 3.2 ES 是可选依赖

Elasticsearch 标记为可选，启动应用不强依赖 ES（`@ConditionalOnProperty`）。这降低部署门槛但意味着"ES 搜索"指标需在装好 ES 的环境单独采集。

## 四、面试话术示例

### 30 秒钩子（简历顶部）

> **EasyOrange — LLM × DDD：Java 架构工程化实战**。在 DDD 六边形里装 LLM：可换供应商、可降级、可观测的 AI 工程化落地。**6 个 AI 决策点全走 Port/Adapter + L1/L2 多级缓存 + 令牌桶限流 + stale 降级 + AiMetrics 可观测 + Prompt 版本化 + Token 预算治理 · 4 ADR 决策记录 · 11 模块 / 2,221 测试守卫 · Java 25 + Spring Boot 4 + React 19**。

### 1 分钟版本（面试自我介绍）

> 我做了一个叫 EasyOrange 的项目，定位是 **LLM × DDD 工程化实战**——在 DDD 六边形架构里集成 LLM，让 AI 链路可换供应商、可降级、可观测。
>
> 核心矛盾：DDD 铁律要求 domain 层零框架依赖，但 LLM 调用昂贵且不稳定必须有多级缓存 + 限流降级 + 可观测。我的解法是 Port/Adapter + 装饰器——`LlmPort` 接口在 domain 层，`@Primary` 装饰器 `CachingLlmAdapter` 在 adapter 层包裹 DeepSeek 实现 L1 Caffeine + L2 Redis 多级缓存；`AiRateLimitInterceptor` 令牌桶按端点限流，超限返回 stale 缓存而不是 429；`AiMetricsService` 把缓存命中率 / LLM p99 / 限流计数暴露到 Prometheus。**6 个 AI 决策点全部走这套链路**。
>
> 架构上 **11 模块** DDD 六边形 + **28 个 Port 接口**全编译期隔离 + ArchUnit 守卫；事件驱动 RabbitMQ + **11 消费者** + DLQ + 指数退避；分布式事务 Saga 编排 + 反向补偿，状态机持久化到 `eo_saga` 表。**4 条 ADR 记录每个"为什么这样选 + 拒绝了什么"**（Saga over 2PC / CQRS scope / AI Port-Adapter / 模块解耦）。测试守卫 **2,221 用例**（后端 1,269 + 前端 952）。

### 被问"为什么不用 2PC"时

> 见 [ADR 0001](./adr/0001-use-saga-over-2pc.md)。三个原因：①平台不经手资金，无 double-spend 风险；②已有 RabbitMQ 基础设施，Saga 编排天然复用；③模块边界已用 Port 隔离，2PC 的强一致收益不抵工程成本。**拒绝了 Seata / XA**。Saga 状态机持久化到 `eo_saga` 表，故障后可 `retryFailedSaga(sagaId)` 重试。

### 被问"AI 怎么工程化的"时

> 见 [ADR 0003](./adr/0003-ai-port-adapter-with-decorator.md)。核心矛盾是 domain 层零框架依赖 vs LLM 不稳定。解法是 **Port/Adapter + 装饰器四件套**：
> - `LlmPort` / `VisionPort` 接口在 domain 层 — 供应商可换
> - `@Primary` 装饰器 `CachingLlmAdapter` 包裹 `DeepSeekLlmAdapter`，实现 L1 Caffeine + L2 Redis 多级缓存
> - `AiRateLimitInterceptor` 令牌桶按端点独立限流（5-30 次/分），超限时返回 stale 缓存而不是 429
> - `AiMetricsService` 暴露缓存命中率 / LLM 延迟 / 限流计数到 Prometheus
>
> 加上 Prompt 版本化（YAML 加载 + `{var}` 渲染）+ Token 预算治理（`@TokenBudget` AOP 切面 + 日预算控制）形成完整 7 件套。**关键词：可换供应商、可降级、可观测——不是调通 API，是工程化**。
