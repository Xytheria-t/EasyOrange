# EasyOrange 技术栈

> 本文档定义了 EasyOrange 项目使用的技术栈及版本要求。

---

## 后端技术栈

| 类别 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 语言 | Java | 25 | 使用 ZGC + Generational 模式 |
| 框架 | Spring Boot | 4.0.3 | 基于 Spring Boot 4.x |
| 安全 | Spring Security | 6.x | JWT 无状态认证 |
| ORM | MyBatis-Plus | 3.5.16 | 逻辑删除、乐观锁、分页插件 |
| 数据库 | MySQL | 8.4 | utf8mb4 字符集，InnoDB 引擎，mysql-native-password=ON |
| 缓存 | Redis | 7.4 | Lettuce 客户端，Caffeine 本地缓存 |
| 搜索引擎 | Elasticsearch | 8.17.3 | Spring Data Elasticsearch 6.0.3，IK 中文分词器 |
| 数据库迁移 | Flyway | 11.15.0 | DDL/DML 分离，生产环境禁止 clean |
| 认证 | JJWT | 0.13.0 | Access Token + Refresh Token 双令牌 |
| 对象映射 | MapStruct | 1.6.3 | 编译期类型安全映射 |
| 结构化日志 | Logstash Logback Encoder | 8.0 | 生产环境 JSON 格式日志 |
| 监控 | Micrometer + Prometheus | — | Actuator 暴露指标端点 |
| 容器化 | Docker + Docker Compose | — | 多阶段构建，非 root 用户运行 |
| 构建工具 | Maven | — | 多模块聚合，统一版本管理 |
| 缓存穿透防护 | 布隆过滤器 (Redis Bitmap) | — | Lua 原子 SETBIT/GETBIT，1% 假阳性率 |
| 分布式 ID | Snowflake | — | Redis WorkerId 自动注册，时钟回拨容忍 10ms |
| 一致性哈希 | 自定义实现 | — | TreeMap + 虚拟节点，MD5 哈希 |
| 消息队列 | RabbitMQ | 3.13 | Spring AMQP 4.0.x，Topic Exchange + Quorum Queue，替代 EventBus + @Async |

## 前端技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | React + TypeScript | SPA 单页应用 |
| 构建 | Vite | 开发服务器 + 生产构建 |
| 样式 | Tailwind CSS | 原子化 CSS + CSS 自定义属性 |
| 路由 | React Router | 声明式路由 |
| 状态管理 | Zustand | 轻量级状态管理 |
| 数据请求 | TanStack Query | 服务端状态管理 + 缓存 |
| 动画 | Framer Motion | 声明式动画 |
| E2E 测试 | Playwright | 端到端测试 |
