## 二、配置管理规范

### 环境配置分层

| 配置文件 | 用途 | 覆盖内容 |
|---------|------|---------|
| `application.yaml` | 基础配置 | 数据源、Redis、MyBatis-Plus、线程池、通用安全配置、虚拟线程、Micrometer Tracing |
| `application-dev.yaml` | 开发环境 | 较小连接池、Flyway 开发数据、JWT 开发密钥、详细日志 |
| `application-prod.yaml` | 生产环境 | 大连接池、SSL、严格安全、JSON 日志、Swagger 禁用 |

### 敏感配置管理

| 配置项 | 管理方式 | 说明 |
|--------|---------|------|
| `JWT_RSA_PRIVATE_KEY` | 环境变量 | 生产环境必须设置 RSA 私钥 PEM 路径 |
| `JWT_RSA_PUBLIC_KEY` | 环境变量 | 生产环境必须设置 RSA 公钥 PEM 路径 |
| `EASYORANGE_DB_PASSWORD` | 环境变量 | 生产环境必须设置 |
| `REDIS_PASSWORD` | 环境变量 | 生产环境必须设置 |
| `RABBITMQ_PASSWORD` | 环境变量 | 生产环境必须设置 |
| `CORS_ALLOWED_ORIGINS` | 环境变量 | 生产环境必须设置白名单 |

**原则**：
- 开发环境提供默认值便于本地启动
- 生产环境必须通过环境变量设置，无默认值
- 禁止在代码或配置文件中硬编码密钥

### JVM 配置

```bash
# 生产环境 Docker 配置
JAVA_OPTS="-Xms256m -Xmx2g -XX:+UseG1GC -XX:+UseStringDeduplication"
SPRING_PROFILES_ACTIVE=prod
```

| 参数 | 说明 |
|------|------|
| `-Xms256m` | 初始堆内存 |
| `-Xmx2g` | 最大堆内存 |
| `-XX:+UseG1GC` | 使用 G1 垃圾回收器 (JDK 25 默认) |
| `-XX:+UseStringDeduplication` | G1 字符串去重，节省堆内存 |
| 优雅停机 | `server.shutdown=graceful`，超时 90s |

### compose.yaml 开发环境

```bash
# 一键启动开发依赖 (MySQL 8.4 + Redis 7.4 + RabbitMQ 3.13)
docker compose -f compose.yaml up -d
```

Spring Boot 4 自动通过 `@ServiceConnection` 发现 compose.yaml 中的服务并配置连接，无需手动设置数据库/Redis/RabbitMQ 地址。

### Docker 多阶段构建

```dockerfile
# 构建命令
cd easyorange-backend
DOCKER_BUILDKIT=1 docker build -f Dockerfile -t easyorange-backend:latest .
```

**镜像特点**：
- 两阶段构建：builder (JDK) → runtime (JRE)
- 非 root 用户运行 (`easyorange:easyorange`)
- 健康检查使用 wget (Alpine 自带，无额外依赖)
- 时区 `Asia/Shanghai`
