## 架构概览

### 技术栈

| 类别 | 技术 | 版本 |
|------|------|------|
| 语言 | Java | 25 |
| 框架 | Spring Boot | 4.0.7 |
| ORM | MyBatis-Plus | 3.5.16 |
| 数据库 | MySQL | 8.4.11 |
| 缓存 | Redis | 7.x |
| 认证 | Spring Security OAuth2 Resource Server | — |

详见 [架构-技术栈.md](架构-技术栈.md)

### 模块划分

```
easyorange-backend (父工程)
├── easyorange-common        # 通用基础模块
├── easyorange-framework     # 框架适配层
├── easyorange-user          # 用户限界上下文
├── easyorange-product       # 商品限界上下文
├── easyorange-order         # 订单限界上下文
├── easyorange-payment       # 支付限界上下文
├── easyorange-message       # 消息限界上下文
├── easyorange-favorite      # 收藏限界上下文
├── easyorange-ai            # AI 限界上下文
├── easyorange-admin         # 管理端限界上下文
└── easyorange-application   # 启动聚合层
```

详见 [架构-系统架构.md](架构-系统架构.md)、[架构-模块结构.md](架构-模块结构.md)

### DDD 分层

```
adapter/           # 六边形适配器层
├── inbound/       # 输入适配器（REST、MQ、Job）
└── outbound/      # 输出适配器（数据库、缓存、RPC）
application/       # 应用层（用例编排、事务管理）
domain/            # 领域层（聚合根、值对象、领域服务）
├── port/   # 出站端口接口
└── repository/    # 仓储接口
```

详见 [架构-DDD规范.md](架构-DDD规范.md)
