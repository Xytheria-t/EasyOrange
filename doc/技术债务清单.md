# EasyOrange 技术债务清单

> 主动列出"已知但选择不还"的技术债。**主动承认技术债 = 工程成熟标志**，比假装"完美无瑕"更可信。
>
> 不主动还债的判断标准：当还债的工程成本 > 债务当前造成的实际损失时，选择不还并文档化。

## 一、债务分类说明

| 级别 | 含义 | 处置策略 |
|---|---|---|
| **接受** | 已知债，当前不还，有明确理由 | 文档化，定期复盘 |
| **待评估** | 短期可接受，中期需还 | 标注触发条件 |
| **必须还** | 影响生产稳定性或安全 | 进入下个迭代 |

## 二、未还债务

### 测试与 CI

**TD-002 · JaCoCo 覆盖率门禁未在本地强制（接受）**
本地只在 `prepare-package` 生成报告，门禁在 CI（保本地编译速度），代价是提交前看不到覆盖率红线。本地补跑命令见 [工程指标.md §2.1](./工程指标.md)。

### 基础设施依赖

**TD-003 · Elasticsearch 标记为可选依赖（接受）**
`@ConditionalOnProperty(easyorange.search.elasticsearch.enabled)` 控制装配；关闭时 `KnowledgeFallbackAdapter` / `ProductSearchIndexAdapter` 接管（prod / dev 显式 true）。
**代价**：ES 路径在无 ES 环境无法验证；降级走 MySQL LIKE，只能命中字面重叠，召回质量差。
**已有缓解**：① `ProdSearchGuard`（`@Profile("prod")`）在环境变量把开关覆盖回 false 时**中止启动**，ES 启用但不可达时 `ElasticsearchIndexManager` 的 `@PostConstruct` 建索引失败同样中止；② `KnowledgeFallbackAdapter` 启动打 WARN + 按调用累计 `easyorange.ai.rag.degraded`，`RagHealthIndicator` 在 `/actuator/health` 报 UNKNOWN 并标注「LIKE 兜底」；③ `ai-eval.yml`（按需 dispatch）起 ES 真实跑知识库召回；④ `ElasticsearchProductSearchIT` 可本地跑。
**残留**：it 及裸跑基文件仍可无 ES 运行；商品检索 DSL 无 CI 覆盖——**这是 CI 覆盖缺口而非闭环**。
**触发重评估**：若未来支持「无 ES 的生产部署」，必须先落地召回的替代实现（进程内向量检索 / VectorStore）并纳入门禁，否则不能移除 `ProdSearchGuard`。

**TD-004 · Redis 单点 + 未做哨兵/集群（待评估）**
单实例足够 demo。代价：Redis 故障时 `RateLimitFilter` 与 `AiRateLimitInterceptor` 均 fail-open（可用性下降但不阻塞）。**触发**：进入生产时升级 Sentinel 或 Cluster。

**TD-017 · Redis 注解缓存读取恒失败（待评估）**
`eo:category:list` 等值写入后按 Object 反序列化恒类型错，每次读打 WARN 并降级直查 DB（fail-open，功能正确）。**代价**：List 类缓存形同虚设 + 日志噪音。**触发**：分类查询量上来或 WARN 干扰排障时——统一写读类型策略（WRAPPER_ARRAY 或缓存值禁用多态），改后存量值靠 30min TTL 自愈。

### AI 工程化

**TD-007 · AI 失败降级策略单一（接受）**
AI 调用失败仅 fail-open（返回 null 或 stale 缓存），用户感知不到降级提示。理由：AI 增强非必需，失败不影响主流程。缓解：Spring AI Observation 暴露成功率/延迟指标，降级频率可在监控面板观察。

**TD-015 · 语义缓存命中率不可测（部分已还）**
**已还**：`eo_ai_call_log` 补 `token_input` / `token_output`（供应商真实回报，未回报记 0、**不估算**）+ 索引；`AiCostReportService` + `GET /api/admin/ai/cost-report` 可按场景聚合调用数 / token 入出 / 平均耗时 / 失败数；embedding 用量改经 `embedForResponse` 取供应商回报的真实 prompt token（此前 `embed(String)` 把响应 metadata 丢在中间层，成本报表 embedding 一行恒 0，预算只能按场景上限虚估）；embedding 调用路径全部纳入记账——`SemanticCacheService`（chat）、`KnowledgeIngestionService`（knowledge）、索引侧商品名向量化经 `QueryEmbeddingPort`（此前直调 `EmbeddingModel`，预算与日志双旁路）。
**仍存在**：① `SemanticCacheService` 无 hit/miss 计数器，命中率不可测；② 预算计数默认在单 JVM 内存（key = 场景:日期，无 TTL，重启清空）——多实例改配置切 Redis 版即口径正确，未切时各算各的。未命中路径的重复向量化已消除（端口拆成 `embedQuery` / `lookUp` / `store`，共用同一次向量化）。
**触发重评估**：需要按用户 / 租户计费或更细的缓存收益核算时——加命中计数器（预算计数的 Redis 化已就位）。

**TD-016 · AI 供应商无跨供应商容灾（接受）**
每场景单供应商（`AiModelRouter` 按 `easyorange.ai.routing.scenarios` 把场景映射到一个 bean），无 failover 链、无应用层断路器；供应商真实故障时降级为 stale 旧答案或 `unavailable` 文案，而不是切到备用模型。理由同 TD-007：AI 增强非必需，现有 stale 降级叙事自洽。**触发**：AI 链路进对外 SLA，或单供应商故障造成可感知损失时——先按场景路由挂第二供应商 bean，再评估应用层断路器。

**TD-019 · AI 搜索增强偶发返回 null 且无提示（待评估）**
`aiEnhanced=true` 时增强偶发失败返回 null，面板整体不渲染、无降级文案（检索结果本身正常）。**触发**：演示翻车或上游趋稳——显式开启且为 null 时显示「AI 分析暂不可用」。

**TD-021 · AI 识别类别回填匹配不上顶级分类（待评估）**
模型返回叶子类目名（如「耳机音箱」），发布表单顶级下拉选不中，类别需手选。**触发**：发布自动化率成为指标时——返回顶级 id 或前端按名映射。

**TD-022 · SSE 客户端断开后仍写 emitter（接受）**
playground 中途离开/连发触发 `ResponseBodyEmitter has already completed` ERROR 日志；仅日志噪音、无用户影响。**触发**：SSE 错误进告警时——发送前检查完成态。

### 安全与运维

**TD-008 · JWT 密钥从配置文件读取（接受）**
未接 Vault / Secrets Manager，轮换需重启、多实例需手动同步。缓解：prod profile 强制环境变量注入。**触发**：进入生产部署时接 Vault 或云厂商密钥服务。

**TD-009 · 文件上传未做病毒扫描（待评估）**
头像 / 商品图只校验 MIME 与大小。**触发**：进入生产时接 ClamAV 或云厂商内容安全服务。

**TD-023 · 冷启动无条件调 /auth/refresh 致 console 401（接受）**
refresh cookie 为 HttpOnly 不可读，前端恢复会话只能盲调，无 cookie 时恒 401（已被静默 catch，仅 console 网络噪音）。**触发**：录屏/console 零错误门禁需要时——后端补非 HttpOnly 标记 cookie 供预判。

### 工程化

**TD-010 · Lombok 在 JDK 25 下产生 unsafe 警告（接受）**
日志噪音；未来 JDK 可能移除 `sun.misc.Unsafe` 导致 Lombok 失效。缓解：JVM 参数已配 `--sun-misc-unsafe-memory-access=allow`。**触发**：Lombok 支持 JDK 25 后移除该参数。

**TD-024 · MessagesPage 列表 key 重复 React 警告（接受）**
进消息中心即出「unique key prop」console 警告（dev 噪音，无渲染错乱证据）。**触发**：console 零警告门禁或列表复用异常时修 key。

**TD-025 · 系统通知会话可输入但消息无回执（待评估）**
会话列表含「系统通知」伪会话，可输入可发送，后端既不落库也不回执，用户侧表现为静默失败。**触发**：消息模块下次迭代——会话禁用输入或后端显式拒绝回执。

**TD-026 · markAsRead 偶发空数组 400（待评估）**
观察到一次 `PUT /api/messages/read` 空列表 → B0002；前端调用点有非空守卫，空数组来源未定位。**触发**：复现或未读角标异常时——后端空列表改 no-op 并补前端 id 守卫。

**TD-027 · pendingProducts 口径取 DRAFT 且 UI 未消费（接受）**
仪表盘字段按 DRAFT 计数（语义应为 PENDING_REVIEW），前端亦无任何展示。**触发**：后台加待审卡片时一并改口径。

**TD-028 · 后台分类分布不聚合子类到顶级（接受）**
按直接挂载计数，顶级行恒 0 被过滤，实际展示叶子分布；叶子口径可用。**触发**：运营要顶级类目口径时聚合子树。

**TD-029 · Eclipse .project/.settings 未入 .gitignore（接受）**
IDE 工作区文件未跟踪但可被整目录 add 误入库（已发生一次、提交前剔除）。**触发**：下次误提交时——.gitignore 补 `.project` / `.settings/`。

**TD-030 · 内部 Page 页大小超 max-limit 被静默截断（接受）**
`easyorange.mybatis-plus.max-limit=100` 把一切 `Page(size>100)` 静默截到 100 行、不报错。`ReindexService` 已修（500→100，2026-09-23 实测 DB ONLINE 101 vs ES 100 暴露）；残留 `MessageQueryRepositoryImpl` 会话历史 `CONVERSATION_HISTORY_LIMIT=500` 单页实际只取 100 条。**触发**：会话翻历史触底、或内部再写 `Page(size>100)` 时——改 `.last("LIMIT n")` 绕过分页拦截器，或常量对齐 100。

### 文档与叙事

**TD-013 · 待实测类数字尚未回填（待评估）**
测试规模 / 覆盖率 / PIT / 压测，以及 AI 运行时指标（LLM 调用 p99 / 限流拒绝次数 / token 消耗），当前一律 `待补实测`——口径与复现命令已就位（[工程指标.md §2](./工程指标.md)）；AI 侧差真实 key（dev 密钥为占位，调用走 fail-open，无法产生真实观测值）。**触发**：配置真实 key 后按 §2.2 采集并回填。
