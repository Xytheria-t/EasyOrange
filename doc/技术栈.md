# EasyOrange 技术栈

> 本文档定义了 EasyOrange 项目使用的技术栈及版本要求。
>
> **版本单一来源**：依赖版本以 `easyorange-backend/pom.xml`（`<properties>`）为准，运行时中间件版本以 `compose.yaml` / `infra/` 镜像 tag 为准；本表与之不一致时以后者为准。

---

## 后端技术栈

| 类别 | 技术 | 版本 | 说明 |
|------|------|------|------|
| 语言 | Java | 25 | 容器内 G1（`Dockerfile` 的 `JAVA_OPTS` 显式 `-XX:+UseG1GC`），非 ZGC |
| 框架 | Spring Boot | 4.0.7 | 基于 Spring Boot 4.x，虚拟线程 (Virtual Threads) 默认启用 |
| AI 框架 | Spring AI (BOM) | 2.0.0 | ADR-0008：`ChatModel` / `EmbeddingModel` 直接注入（OpenAI 兼容协议）+ MCP server（`@McpTool` 公开只读工具面，streamable HTTP `/mcp`） |
| 安全 | Spring Security | 7.0.x | JWT 无状态认证 |
| ORM | MyBatis-Plus | 3.5.17 | 逻辑删除、乐观锁、分页插件 |
| 数据库 | MySQL | 8.4.11 | utf8mb4 字符集，InnoDB 引擎，mysql-native-password=ON |
| 缓存 | Redis | 8.10.0 | Lettuce 客户端；业务缓存为单层 Redis（Caffeine 仅用于 stale / 图片处理等专用本地缓存，多级缓存 2026-08 已移除） |
| 搜索引擎 | Elasticsearch | 9.2.8 | Spring Data Elasticsearch 6.0.6，IK 中文分词器 |
| 数据库迁移 | Flyway | 13.2.0 | DDL/DML 分离，生产环境禁止 clean |
| 认证 | Spring Security OAuth2 Resource Server | — | Access Token + Refresh Token 双令牌，Nimbus JOSE + JWT 引擎 |
| 对象映射 | MapStruct | 1.6.3 | 编译期类型安全映射 |
| 结构化日志 | Spring Boot 4 `StructuredLogEncoder` | — | prod profile 输出 logstash 格式 JSON（`logback-spring.xml`，非 Logstash Logback Encoder 依赖） |
| 监控 | Micrometer + Prometheus + Micrometer Tracing (Brave) | — | Actuator 暴露指标端点，分布式追踪支持 Zipkin |
| 容器化 | Docker + Docker Compose | — | 多阶段构建，非 root 用户运行；compose.yaml 开发环境 (MySQL/Redis/RabbitMQ)，显式 env 直连且凭据统一经根 `.env` 插值 |
| 构建工具 | Maven | — | 多模块聚合，统一版本管理 |
| 缓存 | Spring Cache 注解式 + Redis 单层 | — | `@Cacheable`/`@CacheEvict` 注解驱动，统一短 TTL（`easyorange.cache.default-ttl` 默认 30m），Redis 故障由 CacheErrorHandler fail-open 降级直查 DB |
| 分布式 ID | UUID v7 (RFC 9562) | — | `UuidV7IdGenerator` 为 `@Primary`，零配置零依赖 |
| 消息队列 | RabbitMQ | 4.3.4 | Spring AMQP 4.0.x，Topic Exchange + Quorum Queue，替代 EventBus + @Async |
| 迁移工具 | OpenRewrite | — | Maven 插件，自动化 Spring Boot / Java 版本迁移 |
| 异常响应 | RFC 9457 Problem Details | — | GlobalExceptionHandler 返回 ProblemDetail 标准格式 |

## 前端技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | React + TypeScript | SPA 单页应用 |
| 构建 | Vite | 开发服务器 + 生产构建 |
| 样式 | Tailwind CSS | 原子化 CSS + CSS 自定义属性 |
| 路由 | React Router | 声明式路由 |
| 状态管理 | Zustand | 轻量级状态管理 |
| 数据请求 | TanStack Query | 服务端状态管理 + 缓存 |
| UI 组件库 | shadcn/ui | 基于 Radix UI + Tailwind CSS 的无头组件 |
| 表单校验 | react-hook-form + Zod | 类型安全表单验证 |
| 动画 | Framer Motion | 声明式动画 |
| E2E 测试 | Playwright | 端到端测试 |
| 代码质量 | Biome | 统一 lint + format（替代 ESLint + Prettier） |
