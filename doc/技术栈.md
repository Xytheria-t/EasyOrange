# EasyOrange 技术栈

> 本文档记录技术选型与关键说明；**为什么不选别的**见 `doc/adr/`。
>
> **版本单一来源**：后端依赖版本见 `easyorange-backend/pom.xml`（`<properties>`），前端依赖见 `easyorange-frontend/package.json`，运行时中间件版本见 `compose.yaml` / `infra/` 镜像 tag。**文档一律不复刻版本号**（复刻就得随升级手工同步）；版本漂移校验脚本 `check-version-drift.py` 已从 pre-commit 摘除，待版本表回填时再挂回。

## 后端技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 语言 | Java | 容器内 G1（`Dockerfile` 的 `JAVA_OPTS` 显式 `-XX:+UseG1GC`），非 ZGC |
| 框架 | Spring Boot | 虚拟线程 (Virtual Threads) 默认启用；`StructuredLogEncoder` 输出 logstash JSON |
| AI 框架 | Spring AI (BOM) | ADR-0008：`ChatModel` / `EmbeddingModel` 直接注入（OpenAI 兼容协议）+ MCP server（`@McpTool` 公开只读工具面，streamable HTTP `/mcp`） |
| 安全 | Spring Security | JWT 无状态认证 |
| ORM | MyBatis-Plus | 逻辑删除、乐观锁、分页插件 |
| 数据库 | MySQL | utf8mb4 字符集，InnoDB 引擎，mysql-native-password=ON |
| 缓存 | Redis | Lettuce 客户端；业务缓存为单层 Redis（Caffeine 仅用于 stale / 图片处理等专用本地缓存，多级缓存已移除） |
| 搜索引擎 | Elasticsearch | Spring Data Elasticsearch + IK 中文分词器（**版本硬锁**，见 `infra/elasticsearch/Dockerfile` 注释） |
| 数据库迁移 | Flyway | DDL/DML 分离，生产环境禁止 clean |
| 认证 | Spring Security OAuth2 Resource Server | Access Token + Refresh Token 双令牌，Nimbus JOSE + JWT 引擎 |
| 对象映射 | MapStruct | 编译期类型安全映射 |
| 结构化日志 | Spring Boot `StructuredLogEncoder` | prod profile 输出 logstash 格式 JSON（`logback-spring.xml`，非 Logstash Logback Encoder 依赖） |
| 监控 | Micrometer + Prometheus + Micrometer Tracing (OpenTelemetry) | Actuator 暴露指标端点；Micrometer Observation → OTel 桥 → OTLP 导出 Langfuse |
| LLM 可观测 | Langfuse (自托管) | Spring AI Observation 经 OTLP `/api/public/otel` 上报，每步 prompt / token / 延迟 / 成本可视化；依赖 ClickHouse / PostgreSQL / MinIO / Redis |
| 容器化 | Docker + Docker Compose | 多阶段构建，非 root 用户运行；compose.yaml 开发环境 (MySQL/Redis/RabbitMQ)，显式 env 直连且凭据统一经根 `.env` 插值 |
| 构建工具 | Maven | 多模块聚合，统一版本管理 |
| 缓存（注解式） | Spring Cache + Redis 单层 | `@Cacheable`/`@CacheEvict` 注解驱动，统一短 TTL（`easyorange.cache.default-ttl`）+ 写路径显式 evict，Redis 故障由 CacheErrorHandler fail-open 降级直查 DB |
| 分布式 ID | UUID v7 (RFC 9562) | `UuidV7IdGenerator` 为 `@Primary`，零配置零依赖 |
| 消息队列 | RabbitMQ | Spring AMQP，Topic Exchange + Quorum Queue，替代 EventBus + @Async |
| 迁移工具 | OpenRewrite | Maven 插件，自动化 Spring Boot / Java 版本迁移 |
| 异常响应 | RFC 9457 Problem Details | GlobalExceptionHandler 返回 ProblemDetail 标准格式 |

## 前端技术栈

| 类别 | 技术 | 说明 |
|------|------|------|
| 框架 | React + TypeScript | SPA 单页应用 |
| 构建 | Vite | 开发服务器 + 生产构建 |
| 样式 | Tailwind CSS | 原子化 CSS + CSS 自定义属性 |
| 路由 | React Router | 声明式路由 |
| 状态管理 | Zustand | 轻量级状态管理 |
| 数据请求 | TanStack Query | 服务端状态管理 + 缓存 |
| UI 组件库 | shadcn/ui | 基于 Radix UI + Tailwind CSS 的无头组件 |
| 表单校验 | react-hook-form + Zod | 类型安全表单验证 |
| 动画 | Framer Motion | 声明式动画 |
| E2E 测试 | Playwright | 端到端测试 |
| 代码质量 | Biome | 统一 lint + format（替代 ESLint + Prettier） |
