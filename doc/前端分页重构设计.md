# 前端分页重构设计

## 背景

前端分页使用不统一、覆盖不完整。部分页面缺少分页控件，部分页面使用手写分页逻辑，类型定义存在重复。

## 目标

1. 统一分页类型：`PageResult<T>` 全局唯一，删除 `PageData<T>`
2. 统一分页组件：引入 shadcn/ui Pagination，消除手写分页
3. 补缺：为缺少分页的页面添加分页能力
4. 清理：删除重复代码和类型

## 设计方案

### 1. 类型统一

**操作**：
- 删除 `src/admin/types/admin.ts` 中的 `PageData<T>` 接口
- 将所有 `PageData<X>` 引用替换为 `PageResult<X>`
- 更新 import 为 `@/types` 路径

**影响范围**：6 个 admin hook 文件 + 6 个 admin page 文件 + admin API 文件

### 2. 组件安装

**操作**：创建 `src/components/ui/pagination.tsx`
- 标准 shadcn/ui Pagination 实现
- 导出：`Pagination`, `PaginationContent`, `PaginationItem`, `PaginationLink`, `PaginationPrevious`, `PaginationNext`, `PaginationEllipsis`

### 3. AdminTable 改造

**操作**：AdminTable 内联分页 HTML → shadcn Pagination 组件
- props 接口不变（`pagination?: { current; pageSize; total; onChange }`）
- 仅内部渲染替换
- 保持现有样式一致

### 4. C端页面迁移

| 页面 | 改造内容 |
|------|---------|
| NotificationsPage | 手写 prev/next → shadcn Pagination |
| FavoritesPage | 手写 prev/next → shadcn Pagination |

### 5. 补缺页面

| 页面 | 问题 | 改造内容 |
|------|------|---------|
| OrdersPage | 无分页状态 | 添加 `pageNum` + `pageSize` 状态 + Pagination 组件 |
| MyProductsPage | 硬编码 pageNum:1, pageSize:50 | 替换为状态驱动 + Pagination 组件（pageSize=10 与全局一致） |
| MessagesPage | `getMessages()` 无参数 | 添加 `pageNum`/`pageSize` 参数，后端已支持分页 |

### 6. 维持现状

| 页面 | 方案 | 原因 |
|------|------|------|
| SearchPage | 虚拟滚动 | 浏览型场景，分页不适合 |
| ProductsPage | 无限滚动 | 浏览型场景，分页不适合 |

### 7. SemanticSearchResult 兼容

- `aiApi.ts` 的 `SemanticSearchResult` 缺少 `pages` 字段
- 前端在 API 层补齐：`pages = Math.ceil(total / size)`，保持与 `PageResult` 结构一致

### 8. 抽取 usePagination hook + PaginationBar 组件（优化阶段）

**操作**：
- 创建 `src/hooks/usePagination.ts` — 统一分页状态管理，支持 `resetDeps` 自动回第 1 页
- 创建 `src/components/PaginationBar.tsx` — 包装 shadcn Pagination，带 disabled 语义

**模式**：
```tsx
// Admin 页面
const { pageNum: page, pageSize, goTo } = usePagination({ resetDeps: [keyword, statusFilter] });
<AdminTable pagination={{ current: page, pageSize, total, onChange: goTo }} />

// C端 页面
const { pageNum, pageSize, goTo } = usePagination({ resetDeps: [activeTab] });
<PaginationBar pageNum={pageNum} totalPages={totalPages} onPageChange={goTo} />
```

**影响**：6 个 admin 页面 + 5 个 C 端页面均使用该 hook 和组件，净减 126 行样板代码。

### 9. 清理

- 删除 `admin/types/admin.ts` 中的 `PageData<T>`
- 删除手写分页的 CSS 文件中的旧规则

## 不受影响的部分

- ProductsPage 的无限滚动（IntersectionObserver）
- SearchPage 的虚拟滚动（useVirtualizer）
- 后端逻辑（纯前端改造）
- AdminTable 的 props 接口（保持兼容）
