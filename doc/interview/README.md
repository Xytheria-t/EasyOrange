## 二、怎么读这九册（house style）

九册写法统一，按下面的约定读：

**1. 每节先给「一句话」，再给细节。**
面试的真实顺序也是先结论后展开，所以文档顺序照抄面试顺序。你在 02 里读到一个类，第一眼看到的就是面试时该先说出口的那句。

**2. 句子短。一句一意。**
不用 `·` 把三四件事串成一句。想强调就用句号断句。

**3. 强调只有两种：**

- **加粗** = 必须记住的结论或取舍。一节里不超过三处，加多了就等于没加粗。
- **`⚠`** = 容易翻车的地方（说错就露怯的那种）。04 里凡是带 ⚠ 的都是这类。

**4. 正文里不插链接，链接统一放段末的「延伸」行。**
一句话讲完再跳走，读的时候不用来回折返。

**5. 术语首次出现给英文原名 + 一句话解释**，速查表见 §五。

**6. 册间按节号引用**，见 §四。

## 三、学习协议

### 四个开场白（AI 陪练会话用）

| 你说 | 前置条件 | AI 做什么 |
|---|---|---|
| 「开始第 N 章」 | 无 | 给读码路径卡：入口文件 + 阅读顺序 + 自检问题。**不讲解**。 |
| 「拷打第 N 章」 | 该章白话讲解已归档 | 当面试官连环追问两轮：模块内 + 跨链路。崩的点按三档记入破防清单。 |
| 「继续破防清单」 | 清单里至少有一条 A / B 档 | 抽样考：A 档全考 + B 档抽 3 + 当周新学 2。**从「上次考」日期最老的开始抽**。答对一轮就当场改状态和日期。 |
| 「限时口述第 N 条」 | [01 §1](01-备战清单.md) 第 N 条已合书讲过 ≥1 轮 | 1 分钟讲完 [07 §2.1](07-怎么说.md) 第 N 条 bullet，不许停、不许改口。讲完对照 07 §2.1 与 [02](02-代码走读.md) 校准。 |

> **别在没读过时拷打。** 拷打查的是「学过但崩了」的残留，不是诊断工具。手上还没存量就去拷打，结果只会是「整章都是破防点」——那是课表，不是清单。
>
> **限时口述不能替代拷打。** 拷打查知识盲区（想清楚再答）。限时口述查表达流畅度（边想边说、有时间压力）。「想得清楚但说不流利」是真实面试的独立失败模式。两者各跑一轮，别互相替代。

### 每章固定循环

1. **拿路径卡自读代码。** AI 不讲解；卡住超 30 分钟才解锁讲解，讲完要复述回来。挂手撕题的章在**读过一遍之后**脱参手写——刚读完就写等于抄，写完对照源码的差才是认知空洞。**零存量时（第一次坐下）不先写**：没读过就没有对照的基线，写出来的空白页分不清「忘了」和「没学过」，诊断信号是零。
2. **合上文档写 ≤10 行白话讲解。** 写不出来 = 没读完，回去重读。
3. **拷打。** 链路内一轮 → 跨链路串联一轮。崩的点按档进破防清单。
   *自读和白话讲解没做完的章不拷打。*
4. **校准。** 对照 [02-代码走读](02-代码走读.md) 对应节和源码逐条核，标出「讲错的」和「漏关键点」。讲错的按 A 档 + 备注 `理解偏差`，漏点补成新破防点。
   *校准不得提前：没拷打过就校准等于先给答案再考。*
5. **出关。** A / B 档清零 + 该章挂的 bullet 勾选判据全过。出关产出的白话讲解并入对应册（速答 → 04 / 走读 → 02 / 设计题 → 05）。

### 章节队列（严格顺序，AI 主线在前）

| 章 | 主题 | 出关实验 |
|---|---|---|
| ① | 自治式工具循环 | 本地打流式口跑量，看 `eo_tool_call_step_trace` 与 `easyorange.ai.chat.loop{outcome}` |
| ② | 编排范式判断 | 读 `ToolCallLoop` 控制流，对照 [02 §4](02-代码走读.md) 的收益区论证与三条硬指标，能口述「为什么不做 Workflow」 |

| ⑤ | 成本与延迟治理 | 读 `GET /api/admin/ai/cost-report` 与预算场景配置 |

### 破防清单规则

**台账只有一份**：[01 §7](01-备战清单.md)。本页只定规则，不另存一份——两处台账不互通等于没有进度。

**准入**：只记「自读 + 合书白话讲解」做完后仍然崩的点。还没读到那章的答不出是**未学**不是崩，不入清单；否则清单第一天就等于整本课表。

**分档**（按面试 ROI）：

| 档 | 判据 | 处理 |
|---|---|---|
| **A 挡门** | 这条崩，整条 bullet 讲不了 | 本轮必须清，不许过夜 |
| **B 追问层** | 第 2 层追问崩 | 进清单，按周清 |
| **C 细节** | 第 3 层或纯细节 | **允许认赔**：记「放弃 + 理由」后划掉，理由进 [07 §6](07-怎么说.md) 当绕法素材 |

**状态机**：`崩 → 已答对一轮 → 清零`（连续两轮答对）。答对一轮就当场改状态，别等清零才动——中间态是唯一能看见进度的地方。

**日期**：每条带一个 `上次考`（`YYYY-MM-DD`），**每次被抽到作答当场改当天日期**。它是「最久没碰优先」的排序键；`已答对一轮` 那行的日期即上次答对日期。

**失败类型**（[校准](#每章固定循环)时判定，拷打只能查出「讲不出来」）：

- `讲不出来` → 回去读，按原档处理。
- `讲错了`（与 02 / 源码核对后确认理解有偏）→ **一律按 A 档**，备注 `理解偏差`，先纠错再读。

> 错误理解是自洽的，连环追问问不出来，但面试时自信讲错比支吾更扣分。

**WIP 上限**：未清零的 A + B 档合计 **≤ 12 条**。满了不许开新章，先清债。清债速度追不上新增速度之前，清单只会膨胀成第二本课表。

**出关**：该章挂的 bullet 勾选判据全过（判据见 [01 §1](01-备战清单.md)）。

## 五、名词速查

按第一次出现的册序排。面试里被问到任何一个，读完这行就能接上。

**AI 主线**

| 词 | 一句话 |
|---|---|
| **Agent / 工具循环** | 模型每轮选一个工具 → 我执行 → 结果回灌给模型 → 下一轮，直到收敛。ReAct = 推理 + 行动的循环。 |
| **Tool calling** | 把工具的名字和参数格式（schema）随请求发给模型，模型回「调哪个 + 传什么参数」。执行是自己的事。 |
| **MCP** | Model Context Protocol。把工具按标准协议暴露给 Cursor 这类外部 client 的方式。 |
| **RAG** | 检索增强生成。先从外部知识库检索，把结果拼进 prompt 再生成，用来压幻觉。 |
| **Embedding** | 把文本转成一串数字（向量），语义相近的文本向量距离近。 |
| **kNN** | 用向量距离找最像的 N 条。ES 自带，底层是 HNSW 分层图。 |
| **BM25** | 按词面匹配打分的老牌全文检索。快、准，但只认字不认义。 |
| **两路召回 + RRF** | 语义路和字面路各查一次，再按**排名**（不是分数）融合。两路分数量纲不可比，只有排名能融。 |
| **引用溯源** | 答案里带 `[来源:标题]`，幻觉可以当场核。 |
| **语义缓存** | 把问题和答案一起存起来；下次问相似问题，命中就直接回放，省一次模型调用。 |
| **Token 预算** | 给每个场景设日调用上限，超了降级。切面只做前置检查，记账按供应商回报的真实用量。 |
| **降级 / fail-open** | 出问题时退回次优答案（用旧回答兜底）而不是报错。fail-open 指依赖挂了时放行而不是拒绝。 |
| **流式 / SSE** | 边生成边推给前端。选 SSE 不选 WebSocket，因为单向 + HTTP 自带重连。 |
| **LLM-as-Judge** | 用模型给模型的输出打分。本项目只当回归门禁，不作对外质量证据。 |
| **金标准集** | 人工标注的「标准答案」集合，评估时拿来对照。 |
| **门禁 / EvalGate** | 指标跌破阈值就让 CI 构建失败，防止改 prompt 改崩。 |
| **OTel / Langfuse** | 前者是跨框架的 trace 标准，后者是看 prompt 级链路的开源面板。Grafana 看的是调用级指标。 |

**工程底座**

| 词 | 一句话 |
|---|---|
| **DDD / 六边形** | 业务规则放 domain 层且零框架依赖，外围依赖全走接口（Port）由 adapter 实现。 |
| **聚合根 / 不变量** | 一致性边界。聚合根是入口，也是「哪些规则必须永远成立」的唯一守卫点。 |
| **CQRS** | 读写分离建模。读多写少才值得，否则是双倍代码。 |
| **ArchUnit** | 用测试守住分层规则，CI 上违规直接红。 |
| **ADR** | 架构决策记录。记「为什么选它 + 拒绝了什么」。 |
| **PIT** | 变异测试。往字节码里注入错误改动，测试还全绿说明这个测试没真覆盖。 |
| **Outbox** | 业务表和事件表在**同一个本地事务**里写，提交后异步发。保证「业务成功 = 事件必达」。 |
| **DLQ** | 死信队列。消费失败的消息隔离出来重试，毒消息不阻塞主队列。 |
| **幂等** | 同一个请求执行多次，效果和执行一次一样。 |
| **`SET NX EX`** | 一条原子命令完成「不存在才写 + 设过期」，所以判重不需要额外的锁。 |
| **分布式锁 / watchdog** | 多实例互斥。Redisson 会在快到期时自动续期，不用手工估锁时长。 |
| **缓存三防** | 穿透（查不存在）/ 击穿（热点 key 过期瞬间）/ 雪崩（大面积同时过期）。 |
| **Saga / 2PC / TCC / Seata** | 分布式事务的几种方案。本项目单库，**全族拒绝**，用本地事务。 |
| **虚拟线程** | JDK 21 的轻量线程。IO 阻塞时释放载体线程，不用调线程池参数。 |
