## 三、学习协议

### 四个开场（AI 陪练会话用）

| 开场白 | 前置 | AI 行为 |
|---|---|---|
| 「开始第 N 章」 | — | 给读码路径卡：入口文件 + 阅读顺序 + 自检问题清单，不给讲解 |
| 「拷打第 N 章」 | **该章白话讲解已归档**；没归档就退回上一条，不拷打 | 当面试官连环追问两轮：模块内 + 跨链路串联；崩的点按三档记入破防清单 |
| 「继续破防清单」 | 清单里至少有一条 A/B 档 | 抽样考：A 档全考 + B 档抽 3 + 当周新学 2；**从 `上次考` 日期最老的开始抽**；答对一轮的状态与日期当场改，不留到下一轮 |
| 「限时口述第 N 条」 | [01 §1](01-备战清单.md) 第 N 条已合书讲过 ≥1 轮 | 1 分钟讲完 [07 §2.1](07-怎么说.md) 里第 N 条 bullet，**不许停、不许改口**；讲完对照 07 §2.1 与 [02](02-代码走读.md) 校准，讲错 / 漏点按破防规则处理 |

> **别在没读过时拷打**。拷打的产出是「学过但崩了」的残留，不是诊断工具；手上还没有存量时去拷打，结果只会是「整章都是破防点」——那是课表，不是清单。
>
> **限时口述不替代拷打**：拷打查知识盲区（想清楚再答），限时口述只补表达流畅度这一维（边想边说、总时长有压力）——「想得清楚但说不流利」是真实面试的独立失败模式。两者按 [每章固定循环](#每章固定循环) 各跑一轮即可，别把口述当拷打的替代品。

### 每章固定循环

1. 拿路径卡 → 自读代码（AI 不讲解；卡住超 30 分钟才解锁讲解，讲完须复述回来）
2. 合上文档写 ≤10 行白话讲解（写不出 = 没读完，回去重读）
3. 链路内拷打 → 跨链路串联拷打 → 崩的点按档进破防清单（自读与白话讲解没做完的章不拷打）
4. **校准**（拷打之后）：对照 [02-代码走读](02-代码走读.md) 对应节与 easyorange-backend 源码逐条核，标出「讲错的」与「漏关键点」——讲错的按 A 档 + 备注 `理解偏差`，漏点补成新破防点。**校准不得提前**：没拷打过就校准等于先给答案再考，失去诊断意义
5. A/B 档清零 + 该章挂的 bullet 勾选判据全过 = 出关；出关产出白话讲解并入对应册（速答 → 04 / 走读 → 02 / 设计题 → 05）

### 破防清单（规则）

**台账单一来源**：[01 §7](01-备战清单.md)。本页只定规则，不另存一份——两处台账不互通，等于没有进度。

**准入**：只记「自读 + 合书白话讲解」做完后仍然崩的点。还没读到那章的答不出，是**未学**不是崩，不入清单；否则清单第一天就等于整本课表。

**分档**（按面试 ROI，同 [AGENTS.md 功能取舍判据](../../AGENTS.md)）：

| 档 | 判据 | 处理 |
|---|---|---|
| **A 挡门** | 这条崩，整条 bullet 讲不了 | 本轮必须清，不许过夜 |
| **B 追问层** | 第 2 层追问崩 | 进清单，按周清 |
| **C 细节** | 第 3 层或纯细节 | **允许认赔**：记「放弃 + 理由」后从清单划掉，理由进 [07 §6](07-怎么说.md) 当绕法素材 |

**状态机**：`崩 → 已答对一轮 → 清零`（连续两轮答对）。答对一轮就当场改状态，别等清零才动——中间态是唯一能看见进度的地方。

**日期**：[01 §7](01-备战清单.md) 每条带一个 `上次考`（`YYYY-MM-DD`），**每次被抽到作答当场改当天日期**——没有日期就只能按行序随机抽，复习调度退化。它是「最久没碰优先」的排序键：`已答对一轮` 那行的日期即上次答对日期。

**失败类型**（[校准](#每章固定循环)时判定，拷打只能查出「讲不出来」）：`讲不出来` → 回去读，按原档处理；`讲错了`（与 [02](02-代码走读.md) / 源码核对后确认理解有偏）→ **一律按 A 档处理**、备注注 `理解偏差`，先纠错再读。错误理解是自洽的，连环追问问不出来，但面试时自信讲错比支吾更扣分。

**WIP 上限**：未清零的 A+B 档合计 **≤ 12 条**。满了**不许开新章**，先清债；清债速度追上新增速度之前，清单只会膨胀成第二本课表。

**出关**：该章挂的 bullet 勾选判据全过（判据见 [01 §1](01-备战清单.md)）。
