## 二、怎么读这九册（house style）

九册写法统一，按下面的约定读：

**1. 每节先给「一句话」，再给细节。**
面试的真实顺序也是先结论后展开，所以文档顺序照抄面试顺序。你在 02 里读到一个类，第一眼看到的就是面试时该先说出口的那句。

**2. 句子短。一句一意。**
不用 `·` 把三四件事串成一句。想强调就用句号断句。

**3. 强调只有两种：**

- **加粗** = 必须记住的结论或取舍。一节里不超过三处，加多了就等于没加粗。
- **`⚠`** = 容易翻车的地方（说错就露怯的那种）。04 里凡是带 ⚠ 的都是这类。

**4. 正文里不插链接，链接统一放段末的「延伸」行。**
一句话讲完再跳走，读的时候不用来回折返。

**5. 术语首次出现给英文原名 + 一句话解释**，速查表见 §五。

**6. 册间按节号引用**，见 §四。引用前**先打开那一节核对标题**——`grep '^#'` 只够定位不定性，「设计题 §N」与「手撕题 N」是两回事且编号会撞。

**7. 先白话后要点。** 每节开头先用具体场景（预算三千买笔电这类）讲清这个类在解决什么，再进要点；关键术语就地解释，别只丢进 §五让人自己翻。**判据是「读者手上此刻有什么」**：零存量时「避免形成错误心智模型」这类提醒是空的——他手里没有那个模型。

**8. 元评论放开节末。** 读法顺序、为什么这么排这类，放节末「读完上面再来」，不放节首；前提是读者已经拿到要读的东西。

**9. 只取结论，不复刻已删实现。** 讲一段已从仓库删掉的实现时，只留结论与判据（如「本仓库只有一条编排主线」+ 三条硬指标），实现明细是被追问时才用的弹药。

## 三、学习协议

### 四个开场白（AI 陪练会话用）

| 你说 | 前置条件 | AI 做什么 |
|---|---|---|
| 「开始第 N 章」 | 无 | 给读码路径卡：**源码入口（真实类名）+ 阅读顺序 + 判据问题**。**不讲解**。步骤排序判据是「这一步的产出能不能用于判断下一步」，不是本章交付物的清单顺序。 |
| 「拷打第 N 章」 | 该章白话讲解已归档 | 当面试官连环追问两轮：模块内 + 跨链路。崩的点按三档记入破防清单。 |
| 「继续破防清单」 | 清单里至少有一条 A / B 档 | 抽样考：A 档全考 + B 档抽 3 + 当周新学 2。**从「上次考」日期最老的开始抽**。答对一轮就当场改状态和日期。 |
| 「限时口述第 N 条」 | [01 §1](01-备战清单.md) 第 N 条已合书讲过 ≥1 轮 | 1 分钟讲完 [07 §2.1](07-怎么说.md) 第 N 条 bullet，不许停、不许改口。讲完对照 07 §2.1 与 [02](02-代码走读.md) 校准。 |

> **别在没读过时拷打。** 拷打查的是「学过但崩了」的残留，不是诊断工具。手上还没存量就去拷打，结果只会是「整章都是破防点」——那是课表，不是清单。
>
> **限时口述不能替代拷打。** 拷打查知识盲区（想清楚再答）。限时口述查表达流畅度（边想边说、有时间压力）。「想得清楚但说不流利」是真实面试的独立失败模式。两者各跑一轮，别互相替代。
>
> **学习者质疑某一步时，先判断质疑是否成立再调整**，不要先辩解后让步。

### 每章固定循环

**一次坐下的粒度 = 90 分钟 = 02 的一个节。** 坐下前先定「今天读哪一节」，别在一轮里啃完整章。

0. **前置概念（本章第一次读时做一次）。** 按 [§五](#五概念入门与反查) 查出本章要用的词，只读用到的那几条。**跳过这步，第 1 步一定卡死在概念上**——而卡在概念和卡在代码是两种病，出口不同。
1. **按路径卡读源码。** 路径卡给**源码入口 + 阅读顺序 + 判据问题**；AI 不讲解。卡住分两种：
   - **概念卡**（这个词我不认识）→ 翻 [§五](#五概念入门与反查)，表里没有就问 AI，**立刻解锁**。概念不该耗掉 30 分钟。
   - **代码卡**（概念懂，但读不出这段在干嘛）→ 自己啃，**超 30 分钟才解锁讲解**，讲完要复述回来。

   挂手撕题的章**不在第一次坐下写**：没读过就没有对照基线，空白页分不清「忘了」和「没学过」，诊断信号是零。读过一遍之后再脱参写，写完对照源码的差才是认知空洞。
2. **合上文档写 ≤10 行白话讲解。** 写不出来 = 没读完，回去重读；重读两遍仍写不出，说明卡在第 0 步，回去补概念。
3. **拷打。** 链路内一轮 → 跨链路串联一轮。崩的点按档进破防清单。
   *读源码和白话讲解没做完的章不拷打。*
4. **校准。** 对照 [02-代码走读](02-代码走读.md) 对应节的**「要点 / 追问」**和源码逐条核，标出「讲错的」和「漏关键点」。讲错的按 A 档 + 备注 `理解偏差`，漏点补成新破防点。
   *02 的「要点 / 追问」在这一步之前不看：提前看等于先给答案再考。*「一句话 / 白话 / 骨架」不在此限——它们讲的是「这个类在解决什么」，第 1 步当语境用，不是答案。
5. **出关。** A / B 档清零 + 该章挂的 bullet 勾选判据全过。出关产出的白话讲解并入对应册（速答 → 04 / 走读 → 02 / 设计题 → 05）。

> **整段看不懂的出口（零基础专用）**：第 1 步若某节源码整段读不动（不是某个词陌生，是整段不知道在干嘛），允许先读 02 对应节的「一句话 + 白话 + 骨架」找回语境，再回源码。这是找回语境，不是拿答案——第 4 步仍要老实核。

### 破防清单规则

**台账只有一份**：[01 §7](01-备战清单.md)。本页只定规则，不另存一份——两处台账不互通等于没有进度。

**准入**：只记「读源码 + 合书白话讲解」做完后仍然崩的点。还没读到那章的答不出是**未学**不是崩，不入清单；否则清单第一天就等于整本课表。

**第一次拷打的特例**：某章第一次拷打若 A 档 > 6 条，说明[第 0 步（前置概念）](#每章固定循环)没做完——这一轮**不记账**，补完概念重拷。否则「A 档不许过夜」立刻不可执行。

**分档**（按面试 ROI）：

| 档 | 判据 | 处理 |
|---|---|---|
| **A 挡门** | 这条崩，整条 bullet 讲不了 | 本轮必须清，不许过夜 |
| **B 追问层** | 第 2 层追问崩 | 进清单，按周清 |
| **C 细节** | 第 3 层或纯细节 | **允许认赔**：记「放弃 + 理由」后划掉，理由进 [07 §6](07-怎么说.md) 当绕法素材 |

**状态机**：`崩 → 已答对一轮 → 清零`（连续两轮答对）。答对一轮就当场改状态，别等清零才动——中间态是唯一能看见进度的地方。

**日期**：每条带一个 `上次考`（`YYYY-MM-DD`），**每次被抽到作答当场改当天日期**。它是「最久没碰优先」的排序键；`已答对一轮` 那行的日期即上次答对日期。

**失败类型**（[校准](#每章固定循环)时判定，拷打只能查出「讲不出来」）：

- `讲不出来` → 回去读，按原档处理。
- `讲错了`（与 02 / 源码核对后确认理解有偏）→ **一律按 A 档**，备注 `理解偏差`，先纠错再读。

> 错误理解是自洽的，连环追问问不出来，但面试时自信讲错比支吾更扣分。

**WIP 上限**：未清零的 A + B 档合计 **≤ 12 条**。满了不许开新章，先清债。清债速度追不上新增速度之前，清单只会膨胀成第二本课表。

**出关**：该章挂的 bullet 勾选判据全过（判据见 [01 §1](01-备战清单.md)）。

## 五、概念入门与反查

**两种用法，别混**：

1. **预习**（零基础用）：进第 N 章前，查出本章要用的词，**只读用到的那几条**。「先通读一遍表」是无效动作——记不住，等于没读。
2. **反查**（被问到时用）：面试里被问到任何一个，读完这行就能接上。

后面的表按第一次出现的册序排，是反查用的。**下面这一栏按依赖序排，是预习用的**——进第 1 章前先过它。

### 最小概念集（进第 1 章前必须过的 8 条）

| 词 | 一句话 | 本项目里长什么样 |
|---|---|---|
| **Prompt** | 发给模型的输入文本。 | `prompts/*.yml`；改 prompt 不用改 Java，这是评估门禁存在的理由 |
| **System prompt** | 每次请求置顶、规定角色与边界的那段。 | 工具循环的第一条消息，跨轮逐字不变（吃 KV cache 折扣） |
| **上下文窗口** | 模型单次能接收的 token 上限，超了直接报错。 | `ChatContextTrimmer` 在发出前按 token 估算裁剪 |
| **Token** | 模型计费和限长的基本单位，约等于「一个词的一部分」。 | 预算按 token 记账，供应商回报真实用量 |
| **Function calling / Tool calling** | 模型不直接答，而是回「我要调哪个函数、传什么参数」。两者常混用，本册统一叫 tool calling。 | 工具 schema 随请求下发，模型返回结构化 `tool_calls` |
| **幻觉** | 模型编造出看起来合理但不存在的事实。 | 引用溯源（答案带 `[来源:标题]`）让幻觉当场可核 |
| **Embedding / 向量** | 把文本转成一串数字，语义相近的文本向量距离近。 | 检索的一条腿；另一条腿是字面匹配（BM25） |
| **Chunk / 分块** | 长文档切成的检索最小单位。 | 500 字 + overlap 50，换行优先切点 |
| **Rerank** | 召回之后再精排一遍。 | 本项目**没上**，是[07 §6](07-怎么说.md) 的必问盲区之一 |

> 表里出现了但你还不知道的词（RRF / kNN / HNSW / MRR…），说明它属于更后面的章，现在不用管。

**AI 主线**

| 词 | 一句话 |
|---|---|
| **Agent 循环** | 模型每轮自己决定下一步 → 我执行 → 结果回灌 → 下一轮，直到收敛。**判据是「下一步由谁决定」，不是「用了工具」**——工具只是执行手段。业内也叫 ReAct 循环：ReAct（Yao et al. 2023）是这个思路的源头范式（提示词拼 Thought/Action/Observation 文本再解析），本项目是它的原生 tool calling 实现，同源不同物。 |
| **Tool calling** | 把工具的名字和参数格式（schema）随请求发给模型，模型回「调哪个 + 传什么参数」。执行是自己的事。 |
| **编排范式** | 「多步任务按什么顺序走」的选择。两种极端：Workflow（流程写死在代码里）与自治循环（每步问模型）。 |
| **Workflow** | 流程写死的编排方式。好处是确定性强、超时可整体设、成本可预测，代价是流程外的分支直接僵住。 |
| **Schema** | 结构化描述，这里指「一个工具叫什么、收什么参数、返回什么」的 JSON 格式说明，随请求发给模型。 |
| **AOP / 切面** | 在方法调用前后自动织入的横切逻辑。本项目用它做预算前置检查、按场景限流、调用记账。 |
| **MCP** | Model Context Protocol。把工具按标准协议暴露给 Cursor 这类外部 client 的方式。 |
| **RAG** | 检索增强生成。先从外部知识库检索，把结果拼进 prompt 再生成，用来压幻觉。 |
| **Embedding** | 把文本转成一串数字（向量），语义相近的文本向量距离近。 |
| **kNN** | 用向量距离找最像的 N 条。ES 自带，底层是 HNSW 分层图。 |
| **BM25** | 按词面匹配打分的老牌全文检索。快、准，但只认字不认义。 |
| **两路召回 + RRF** | 语义路和字面路各查一次，再按**排名**（不是分数）融合。两路分数量纲不可比，只有排名能融。 |
| **引用溯源** | 答案里带 `[来源:标题]`，幻觉可以当场核。 |
| **语义缓存** | 把问题和答案一起存起来；下次问相似问题，命中就直接回放，省一次模型调用。 |
| **Token 预算** | 给每个场景设日调用上限，超了降级。切面只做前置检查，记账按供应商回报的真实用量。 |
| **降级 / fail-open** | 出问题时退回次优答案（用旧回答兜底）而不是报错。fail-open 指依赖挂了时放行而不是拒绝。 |
| **stale** | 「上次的结果」。供应商挂了就把它返给用户，比报错好。 |
| **trace / Observation** | trace = 一次请求从头到尾的完整调用链；Observation = 链上的一个观测点，每次调模型产生一个。 |
| **多模态** | 一个模型同时处理文字和图片。本项目用在发布助手的拍照识别。 |
| **流式 / SSE** | 边生成边推给前端。选 SSE 不选 WebSocket，因为单向 + HTTP 自带重连。 |
| **LLM-as-Judge** | 用模型给模型的输出打分。本项目只当回归门禁，不作对外质量证据。 |
| **金标准集** | 人工标注的「标准答案」集合，评估时拿来对照。 |
| **门禁 / EvalGate** | 指标跌破阈值就让 CI 构建失败，防止改 prompt 改崩。 |
| **OTel / Langfuse** | 前者是跨框架的 trace 标准，后者是看 prompt 级链路的开源面板。Grafana 看的是调用级指标。 |

**工程底座**

| 词 | 一句话 |
|---|---|
| **DDD / 六边形** | 业务规则放 domain 层且零框架依赖，外围依赖全走接口（Port）由 adapter 实现。 |
| **聚合根 / 不变量** | 一致性边界。聚合根是入口，也是「哪些规则必须永远成立」的唯一守卫点。 |
| **CQRS** | 读写分离建模。读多写少才值得，否则是双倍代码。 |
| **水平越权** | 用别人猜得到 / 伪造得到的标识（别人的 sessionId）访问到他的数据。防法是把 key 绑到登录身份上。 |
| **ArchUnit** | 用测试守住分层规则，CI 上违规直接红。 |
| **ADR** | 架构决策记录。记「为什么选它 + 拒绝了什么」。 |
| **PIT** | 变异测试。往字节码里注入错误改动，测试还全绿说明这个测试没真覆盖。 |
| **Outbox** | 业务表和事件表在**同一个本地事务**里写，提交后异步发。保证「业务成功 = 事件必达」。 |
| **DLQ** | 死信队列。消费失败的消息隔离出来重试，毒消息不阻塞主队列。 |
| **幂等** | 同一个请求执行多次，效果和执行一次一样。 |
| **`SET NX EX`** | 一条原子命令完成「不存在才写 + 设过期」，所以判重不需要额外的锁。 |
| **分布式锁 / watchdog** | 多实例互斥。Redisson 会在快到期时自动续期，不用手工估锁时长。 |
| **缓存三防** | 穿透（查不存在）/ 击穿（热点 key 过期瞬间）/ 雪崩（大面积同时过期）。 |
| **Saga / 2PC / TCC / Seata** | 分布式事务的几种方案。本项目单库，**全族拒绝**，用本地事务。 |
| **虚拟线程** | JDK 21 的轻量线程。IO 阻塞时释放载体线程，不用调线程池参数。 |
