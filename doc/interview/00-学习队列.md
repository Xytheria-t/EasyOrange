# 学习队列与自测协议

> 面试准备的操练手册：按队列逐章吃透项目。本文件是学习协议的单一来源，AI 会话按此配合执行。

## 一、会话接口（新会话开场三选一）

| 开场白 | AI 行为 |
|---|---|
| 「开始第 N 章」 | 给读码路径卡：入口文件 + 阅读顺序 + 自检问题清单，不给讲解 |
| 「拷打第 N 章」 | 当面试官连环追问两轮：模块内 + 跨模块串联；卡壳点记入破防清单 |
| 「继续破防清单」 | 只考破防点，全部答对（清零）才出关进下一章 |

## 二、每章固定循环

1. 拿路径卡 → 自读代码（AI 不讲解；卡住超 30 分钟才解锁讲解，讲完须复述回来）
2. 合上文档写 ≤10 行白话讲解（写不出 = 没读完，回去重读）
3. 模块内拷打 → 跨模块串联拷打 → 破防点进清单
4. 破防清零 = 出关；出关产出：白话讲解并入 [02-项目深挖.md](02-项目深挖.md) 对应节

## 四、破防清单
