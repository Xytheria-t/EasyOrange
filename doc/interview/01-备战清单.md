## 7 破防清单

> **规则在 [README](README.md)**（准入 / 分档 / 状态机 / WIP 上限）。**本册是唯一台账**——别在别处再记一份。

**准入**：只记「自读 + 合书白话讲解」做完后仍然崩的点；还没读到那章的答不出是未学，不记。

**档**：**A** 挡门（整条 bullet 讲不了，本轮必清）· **B** 追问层（第 2 层崩，按周清）· **C** 细节（第 3 层或纯细节，可认赔）。

**失败类型**（[校准](README.md#每章固定循环)时判定）：`讲不出来` → 回去读，按原档处理；`讲错了`（与 02 / 源码核对后确认理解有偏）→ **一律按 A 档处理**、备注注 `理解偏差`，先纠错再读。校准发现的漏关键点补一条新破防点，按影响面定档（整条 bullet 讲不了 = A）。

| 档 | 章 / 来源 | 破防点 | 状态 | 上次考 | 备注（理解偏差 / 认赔理由 / 归到哪条 bullet） |
|---|---|---|---|---|---|
| | | | | | |

**状态写法**：`崩` → `已答对一轮` → `清零`（连续两轮答对）；C 档放弃写 `认赔`，理由搬进 [07 §6](07-怎么说.md) 当绕法素材。

**「上次考」写法**：`YYYY-MM-DD`，**每次被抽到作答就当场改当天日期**——它就是「最久没碰优先」的排序键，「继续破防清单」从日期最老的开始抽。`已答对一轮` 那行的日期即上次答对日期；新条目录入当天也记一次。

**WIP 上限**：未清零的 A+B 档合计 ≤ 12 条，满了先清债、不开新章。
