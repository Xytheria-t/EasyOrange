## 4 行为面 / HR 面

> HR 面不是技术面——**每个答案 1-2 分钟，用 STAR 结构**（情境-任务-行动-结果），结果尽量带数字；**学生身份下不要套用社招话术**（不提「前东家」「离职原因」）。

**H1 自我介绍（HR 版，30 秒）**
→ 参考：07 §3.1（开场抛钩子：定位 + 两条链路 + 底座）

**H2 为什么做这个项目？**
→ STAR：看到「AI 应用工程化落地难」（模型能调通、但限流 / 降级 / 预算 / 评估 / 观测一片空白）→ 自己定两条业务主线 + 一套生产级标准 → 单人完成后端 + 前端 → 门禁、降级、评测、观测齐备。**不要**说「为了找工作」——说「用生产标准自证工程能力」。

**H3 项目遇到的最大困难？**
→ 推荐叙事（选一）：技术选型推翻重来（自研 AI 抽象 → Spring AI 框架化，ADR-0003 → 0008）；一致性架构回退（Saga → 本地事务 + Outbox，ADR-0001 → 0007）；余弦重排等于没排的识别与删除（ADR-0012）。

**H4 怎么评价自己？短板是什么？**
→ 先说强项（AI 工程化落地 + 编排设计 + 测试与门禁意识），短板说一个**真实且正在补**的：「Spring AI 源码级细节还没吃透（Bean 注册 / 工具回调内部），在读源码；LangGraph 多智能体编排是第二个项目的技术栈，还没上手」——诚实 + 行动闭环。

**H5 你是学生，怎么平衡学业与项目？能实习多久？**
→ 「2025 级软件工程本科，2029 届，目标大三进一线大厂实习。项目是课外按生产标准自驱做的，每周固定投入 ≥10h，时间边界清楚；实习时长按学校安排（暑期可全职 / 学期内可日常实习），能稳定投入。」**不要**提任何学生职务。

**H6 为什么投我们 / 为什么选这个方向？**
→ 目标导向：想做 Agent / AI 应用工程化方向的工程实践（不是调 API 的 demo），结合项目讲 1-2 个具体匹配点，显示做过功课。

**H7 期望薪资？**
→ 实习语境：先问对方实习薪酬带宽与转正机制，再报预期区间；「我更看重方向与成长，薪酬在贵司标准内匹配即可」。**别**用社招话术谈「职级带宽」。

**H8 你还有什么想问的？（必准备）**
→ 技术向反问：「你们团队的 Agent 循环是自研还是框架托管？步数与成本怎么控制？」「LLM 链路的降级和预算治理怎么做的？」「检索是纯向量还是混合召回？」别问：技术栈是什么 / 加班多吗 / 有食堂吗。
