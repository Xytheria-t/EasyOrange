# 模拟面试题库

> **什么时候翻**：让朋友或自己按题号逐条问，答完对照「参考位置」自查。
> **全册 28 条**（§1 的 18 + §2 的 10），每条都要答到**第 3 层追问**——全刷一遍是十几小时的量，**一次坐下 45 分钟只做 6~8 条**。
> **目标**：每条主线答到第 3 层追问不崩。每条追问链模拟真实面试的「问题 → 追问 → 深挖」节奏，不是孤立题库。
> **数字只在 [工程指标.md](../工程指标.md)**，结构计数只引[「结构计数」](../工程指标.md#结构计数)锚点。

## 怎么用

1. 让对方只念**粗体的主问题**，不念追问。答完再念追问。
2. 每答一层就停下来核对参考位置，对不上当场记进 [01 §7](01-备战清单.md) 破防清单。
3. 「崩在第几层」要标清楚——**没被追到第 3 层只说明表层稳，不代表深水区稳**。

**参考位置写法**：`07 §x` = [07-怎么说](07-怎么说.md) 对应节；`04 AI-1` = [04-速答](04-速答.md) 的题号；`06 §1.9` = [06-工程底座](06-工程底座.md) 对应小节；`02 §6` = [02-代码走读](02-代码走读.md)；`05 §2` = [05-设计题与手撕](05-设计题与手撕.md) 设计题、`05 题 1` = 该册手撕题。

## 4 行为面 / HR 面

> **每个答案 1-2 分钟，用 STAR 结构**（情境 - 任务 - 行动 - 结果），结果尽量带数字。学生身份下**不要套用社招话术**（不提「前东家」「离职原因」）。

**H1 自我介绍（HR 版，30 秒）** → [07 §3.1](07-怎么说.md)（开场抛钩子：定位 + 两条链路 + 底座）

**H2 为什么做这个项目？**
→ STAR：看到「AI 应用工程化落地难」（模型能调通，但限流 / 降级 / 预算 / 评估 / 观测一片空白）→ 自己定两条业务主线 + 一套生产级标准 → 单人完成后端 + 前端 → 门禁、降级、评测、观测齐备。
> **不要说「为了找工作」**——说「用生产标准自证工程能力」。

**H3 项目遇到的最大困难？** → 选一个讲：

- **技术选型推翻重来**——自研 AI 抽象 → Spring AI 框架化（ADR-0003 → 0008）
- **一致性架构回退**——Saga → 本地事务 + Outbox（ADR-0001 → 0007）
- **无效实现的识别与删除**——余弦重排等于没排（[ADR-0012](../adr/0012-rag-hybrid-retrieval-rrf.md)）

**H4 怎么评价自己？短板是什么？**
→ 先说强项（AI 工程化落地 + 编排设计 + 测试与门禁意识）；再说一个**真实且正在补**的短板：「Spring AI 源码级细节还没吃透（Bean 注册 / 工具回调内部），在读源码；LangGraph 多智能体编排是第二个项目的技术栈，还没上手」——**诚实 + 行动闭环**。

**H5 你是学生，怎么平衡学业与项目？能实习多久？**
→ 「2025 级软件工程本科，2029 届。项目是课外按生产标准自驱做的，时间边界清楚。」后半句**按目标池分版，别串**（⚠️ 说错版本等于自认跳板或自降档次）：
  - **中小厂 / 创业（寒假远程池）**：「想找一段能长期延续的远程实习——寒假每周 20h、开学后 15h，能做 6 个月以上」。**不提大厂**。
  - **大厂**：「目标大三进一线大厂实习」。
> **数字不在这里另立口径**，照 [07 §6.1⑩](07-怎么说.md) 那一组说（必须与投递话术完全一致，被追问两次就露馅）；「开学后能延续」要先在[迭代路线 §三](../迭代路线.md)待确认项坐实再用。**不要**提任何学生职务。

**H6 为什么投我们 / 为什么选这个方向？** → 目标导向：想做 Agent / AI 应用工程化方向的工程实践（不是调 API 的 demo），结合项目讲 1-2 个具体匹配点，显示做过功课。

**H7 期望薪资？** → 实习语境：**先问对方实习薪酬带宽与转正机制**，再报预期区间。「我更看重方向与成长，薪酬在贵司标准内匹配即可。」
> **别**用社招话术谈「职级带宽」。

**H8 你还有什么想问的？（必准备）** → **技术向反问**：

- 「你们团队的 Agent 循环是自研还是框架托管？步数与成本怎么控制？」
- 「LLM 链路的降级和预算治理怎么做的？」
- 「检索是纯向量还是混合召回？」

**别问**：技术栈是什么 / 加班多吗 / 有食堂吗。
