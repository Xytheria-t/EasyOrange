# easyorange-frontend/src/components/profile/

## Responsibility

User profile/personal center sidebar components (user info card, navigation tabs, password modal).

## Files

| File | Responsibility |
|------|---------------|
| `ProfileSidebar.tsx` | Sidebar with avatar, user info, action buttons (发布商品/我的发布/购买记录/退出), nav tabs |
| `ProfileOverview.tsx` | Main overview tab — metrics grid, AI assistant, quick actions, personal info cards |
| `ProfileActivity.tsx` | User activity history tab |
| `ProfileSecurity.tsx` | Security settings tab (password change, score) |
| `ProfilePreferences.tsx` | Preferences tab (theme, notifications) |
| `ProfileSetupModal.tsx` | First-time profile setup modal |
| `PasswordModal.tsx` | Password change dialog |
