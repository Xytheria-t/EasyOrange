# 跨层级重复注释白名单 —— check-comment-dup.py 的语义例外
#
# 格式：<仓库相对路径>|<归一化后的注释文本>  # <理由>
#   归一化 = 剥掉 {@link}/{@code} 引用、去标点与空白后的纯文本，
#           用 `python3 .githooks/check-comment-dup.py --emit` 生成待粘贴行。
#   按「文件 + 注释文本」匹配而非行号 —— 改动行号不会让条目失效。
#   # 后面的理由是必填项：没写理由的条目等于免死金牌，评审时无法判断该不该留。
#
# 什么样的例外值得开：类注释讲的是「契约」，行内注释锚的是「字面量含义」，
# 读者看代码时眼睛停在调用现场、不会往上翻十几行。纯措辞不同的重复不算例外。

easyorange-backend/easyorange-framework/src/main/java/com/cartethyia/easyorange/framework/lock/DistributedRedissonLockAdapter.java|leaseTime1由Redissonwatchdog续期避免固定租约在操作结束前自动过期  # 类注释把 leaseTime=-1 列为契约第三条（面向读者）；行内这句面向的是 tryLock(timeout, -1, SECONDS) 的 -1 字面量——Effective Java 的「解释魔数」，读者停在调用现场不会往上翻 15 行
